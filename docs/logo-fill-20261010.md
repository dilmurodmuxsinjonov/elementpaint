# Logo-contained Berlak paint introduction

The original transparent Element Paint logo is shown as translucent relief against the warm light background. The Berlak PF-115 Snow White / Qordek oq can tips, pouring an ivory-white stream into the original logo. Its label asset is retained unchanged. This replaces the former external puddle and mismatched green logo fill.

The logo's native alpha is the sole liquid boundary. The crest, lettering, counters and negative spaces remain intact. A damped height field disturbs the rising surface; the meniscus and impact reflections use the same alpha clip. At full fill the wave envelope settles and every opaque logo pixel is covered. The can returns upright before the introduction fades into the site, approximately 4.45 seconds after starting. Skip, Escape, reduced motion and replay retain their existing behavior.

The stage is a Canvas animation; it does not claim to be filmed paint or a volumetric fluid solver. Snow White is matched to the existing package rather than introducing an unapproved catalogue colour. The progress meter is the animation's completion, not measured network download progress.

Validation:

- `tests/verify_logo_fill.html`: nine rendered frames, including 0%, intermediate fill, 100%, reset and refill. Zero liquid pixels outside native logo alpha; no unfilled opaque pixels at 100%; pour entry inside the original logo.
- `tests/test_paint_liquid.mjs`: wave propagation, damping, large-frame stability and replay reset passed.
- Catalogue verification: 45 approved products, 34 colours, 72 packages and 20 legacy links passed. All 72 package images still match original PDF extraction hashes.
- Browser: light/dark pouring, 375 × 812 phone viewport, automatic completion, replay, skip and reduced-motion replay suppression. No warnings/errors on the local page.
- Preview packaging includes the new `paint-logo.js` module, excludes the test fixture and work files, and sets app version `20261010.4`.

Publication is restricted to `preview-site`. Production/main and the main hosting server are outside this change.
